Name the parts

Five jobs. Every control does one of these.

Stay — Bar (every frame). Tabs switch jobs: not today. Search finds a crowd: three slots is not a crowd.

Scan — Row (pick one of several). Card (hold one thing still). Chip filters. Badge counts. Empty: one sentence, one verb.

Enter — Field (one fact, label stays). Toggle is on/off. Select is a known list. Pin-up only needs Note.

Commit — Button (one verb: Book). Sheet (decide without leaving). FAB creates; not today. Dialog is a hard stop: Delete, not Book.

After — Toast (what happened, stay). Banner stays until they deal. Spinner stays on this screen.

Today on the phone: Bar · Row · Card · Field · Button · Sheet · Toast. The rest you can name. Leftover is literacy. Using it anyway is decoration.

Teach Figma · all 13 videos

Hour 2 is the full Figma Design for beginners playlist. Written twin: Help Center. Their object is a portfolio site. Ours is the meditation kit. Question. Wait. Lime name. Then they do it.

1 · Course overview — Apps, sites, illustrations. Starter plan. Browser or desktop.

2 · Set up your account — figma.com/signup. File browser. Recents, drafts, teams. Duplicate the Meditation App UI Kit. Name Calm. Education if student email.

3 · Navigate files — Toolbar, left, canvas, right. File / Assets. Design / Prototype. Space or H pan. Zoom. Pages: kit pages stay. Add Our flow. Nudge in Preferences (1 / 10).

4 · Landing page hero — Layers. Six shape tools (R, L, Shift+L, O, Shift+O, Star). Fill, image fill. Text (auto width / height / fixed). Align. Nudge. Frame. Nest layers in the frame.

5 · Case study page — Frame presets (phone 390 × 844). Heading, paragraph, quote. Constraints (top-left default). Tidy. Smart selection. Group is not a section is not a frame.

6 · Create the button — Auto layout: flow, gap, padding, alignment, hug / fill / fixed. Type Book. Shift+A. Radius 8. Cmd-Opt-K.

7 · Components fundamentals — Main vs instance. Create multiple. Apply. Push changes. Reset. Detach last. Variants for Booked.

8 · Card and container — Card with auto layout. Container wrap. Fill on a phone. Move mains to Components. Then map the kit, 15 min.

9 · Navigation and footer — Nav: wordmark, links, button instance, auto gap, fill width. On the phone that is Bar. No website footer.

10 · Skills list — Boolean: union, subtract, intersect, exclude. Vector edit. Ellipse arc. Instance swap. Wrap. Selection colors. Home still uses Cards.

11 · Assemble — Assets onto Our flow. Four frames. Welcome, Home, Session, Player. 40 min.

12 · Prototype connections — Flow. Trigger, action, animation. Noodles. Get started → Home → Session → Player. Present. Sticky / fixed / ignore auto layout / scroll to (named; not required today). Play 20 min.

13 · Course summary — They can start bringing ideas to life. Pass is still a stranger starting a session.
