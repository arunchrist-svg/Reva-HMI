Make the screen

Keep this open while you build.

One phone frame. Your project’s primary task. Rectangles and text. No kit. No AI layout.

Your task

Write this at the top of the Figma page, in a text box:

A [person] can [task] without [barrier].

That sentence is the name of Frame 1. If you cannot write it, you are not ready to draw.

Open Figma

  1. Go to figma.com. Sign in. Education plan if you have a student email.
  2. New Design file.
  3. Press F. Choose a Phone frame, or set size to 390 × 844.
  4. Rename the frame with the task sentence.
  5. Draw: R rectangle, T text. Fill. That’s enough today.

One file per group. Two people at the keyboard, max. Sit with a neighbour if the tool is new. Do not wait for a lecture.

The six

Use only these. If you invent a seventh, ask which of these it is.

  1. Button — one primary action, large enough to hit.
  2. Input + label + helper — a field someone can fill without guessing.
  3. List / card — choose one of several things.
  4. Navigation — where am I, how do I get back.
  5. Empty state — first use, nothing there yet, what now.
  6. Error / success — what the system did, what to do next.

Version 2 needs three frames: happy path, empty, error or success.

Five laws

Name a law only when you change the screen.

  1. Fitts — small or far targets take longer. Make the primary big and close to the thumb.
  2. Hick — too many equal choices freeze people. One primary. Hide or delay the rest.
  3. Jakob — people know other apps better than yours. Do not invent a new control.
  4. Miller — working memory is small. Do not dump twelve fields on one step.
  5. Postel — accept messy real input; be strict on what you store. Spaces in a phone number should not fail the form.

From Session 1, still in play: affordance, signifier, feedback. If you have to explain the tap, it failed.

Share

  1. Label Version 1 and Version 2 on the same page.
  2. Three sticky notes on Version 2: the change, and the law.
  3. Share → Anyone with the link can view.
  4. Paste the link in the class sheet. Open it in a private window.

If a stranger sees the three frames in twenty seconds, you are done.
