The file

Work in your duplicate. Look at the class file only as the picture of what to assemble. Do not edit the community original.

  1. Open Meditation App UI Kit.
  2. Open in Figma → Duplicate. One file per group.
  3. Keep this open beside you: exact designs.
  4. In your copy, add a page: Our flow.

Light mode today. Dark mode, Sign in, Profile stay unused.

Build it DS-style

A design system is proven when changing one component moves every screen. If you detach, you have souvenirs.

  1. Assets panel. Drag instances. Never redraw a button.
  2. Override text and images only. Do not explode the frame.
  3. Auto layout stays. If you break it: Shift+A.
  4. Variants: switch Light / state in the right sidebar. Do not restyle by hand.
  5. Do not detach. ⌥⌘B is last resort.
  6. Mains live on the kit pages. Our flow only gets instances.

What they do

  1. Page Our flow. Four frames, F · 390 × 844. Name them Welcome, Home, Session, Player.
  2. From Assets, instance the matching kit screens onto those frames. Or copy the kit frame as an instance, then swap.
  3. Map the parts you named this morning: Bar, Card, Button. Leftovers (tabs, search, FAB, dark mode) stay in the library.
  4. If a screen is already a component in the kit, use that instance. Do not flatten it.

If it does not look like the class file, you redrew. Undo. Instance again.

Prototype

  3. One session card → Navigate to Session. Instant.
  4. Start / Play → Navigate to Player. Instant.
  5. Present. Give the laptop to the next group. Stay quiet.
